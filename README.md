# OfficeManager

برنامج سطح مكتب (Python 3.12 + Tkinter/ttk + SQLite) لمكتب خدمات جزائري:
توليد مستندات العمل اليومية من استمارات تُملأ فوق نموذج الوثيقة مباشرةً،
مع أرشفة وسجلّ لكل ما يُولَّد.

الواجهة عربية؛ المستندات المولَّدة بالفرنسية.

---

## التشغيل

```
python main.py
```

- **النواة** (العملاء، الأرشفة، قاعدة البيانات، محرّك الأجور) تعتمد على
  المكتبة القياسية فقط.
- **توليد المستندات** (خدمة CD وشاشات الموارد البشرية) يحتاج:
  `python-docx` · `Pillow` · `reportlab` — راجع `requirements.txt`.

```
pip install -r requirements.txt
```

الدخول محميّ باسم مستخدم + كلمة مرور (`programme/auth.py`)، مع قفل تلقائي
بعد خمول (`ui/lock_overlay.py`) وسجلّ جلسات.

---

## الخدمات الحالية

| الخدمة | الوصف | المستند |
|---|---|---|
| **CD** | Change Devise — بيع/شراء عملة | `ui/cd/` |
| **شهادة عمل** | Attestation de travail | `ui/hr/attestation_travail.py` |
| **شهادة عطلة** | Titre de congé | `ui/hr/titre_conge.py` |
| **كشف راتب شهري** | Bulletin de paie | `ui/hr/bulletin_paie.py` |
| **كشف راتب سنوي** | Relevé annuel des émoluments | `ui/hr/releve_annuel.py` |

كل خدمة = تبويب حيّ يبقى بحالته الكاملة في الذاكرة عند التنقّل، مع شريط
ملفات جانبي (`ui/common/file_explorer.py`) مصدره قاعدة البيانات.

## وحدة الأجور — `programme/payroll/`

`docs/specs/SPEC_PAIE_DZ.md` هو **المرجع الإلزامي** لهذه الوحدة. أي تعديل
على منطق الحساب يلتزم به حرفياً. الجوهر:

1. **لا رقم قانوني داخل الكود** (SNMG، شرائح IRG، النسب، معاملات التنعيم).
   كلها في `programme/data/params_paie/params_<سنة>.json`، ويُختار الملف
   حسب نافذة صلاحيته (`en_vigueur_du` / `en_vigueur_au`) المطابقة لتاريخ
   الكشف — حتى تُحسب كشوف السنوات السابقة بمعاملات سنتها.
2. **`Decimal` حصراً** في كل ما يتعلق بالمال — ممنوع `float`.
3. النطاق: العامل الأجير في الحالة العادية فقط (لا متقاعدين / ذوي إعاقة).
4. سلسلة الحساب: `أساس CNAS × النسبة → أساس IRG = (أساس − اقتطاع CNAS)
   + المنح المعفاة من الاشتراك الخاضعة للضريبة → IRG بالشرائح`.

### الاختبارات الذهبية

يجب أن تمرّ قبل أي إصدار (T1→T8 لدالة IRG، مطابقة لجدول §5 من المواصفة):

```
python -m unittest programme.payroll.tests.test_golden
python programme/payroll/tests/test_golden.py      # تقرير جدول مقروء
```

## البيانات والنسخ الاحتياطي

- قاعدة البيانات: `office_system.db` (SQLite، بجذر المشروع) — فيها بيانات
  المكتب الحقيقية، **مستثناة من git** (`.gitignore`). نسخة احتياطية =
  نسخ هذا الملف.
- مجلد الشغل: `travail/` على سطح المكتب الحقيقي (لا داخل مجلد البرنامج) —
  كل خدمة تأخذ مجلدها الفرعي، وملفات الزبائن مسطّحة جوّاه.
- ملفات الإعدادات المحلية (`cd_settings.json`، `hr_settings.json`،
  تفضيلات الشريط…) خاصة بالجهاز ومستثناة من git.
