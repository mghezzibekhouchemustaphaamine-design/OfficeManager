# نظام إدارة الأعمال المكتبية

برنامج سطح مكتب بلغة Python (Tkinter + SQLite) لإدارة الأعمال المكتبية اليومية.

## المميزات

- **🏠 الرئيسية**: نظرة عامة سريعة (عدد العملاء، الفواتير غير المدفوعة وقيمتها، المهام القريبة).
- **👥 العملاء**: إضافة/تعديل/حذف/بحث عن العملاء (الاسم، الهاتف، البريد، العنوان، ملاحظات).
- **🧾 الفواتير**: إنشاء فواتير مرتبطة بعميل، إضافة بنود متعددة مع حساب الإجمالي تلقائياً، تتبع حالة الدفع، وتصدير القائمة كـ CSV.
- **✅ المهام والمواعيد**: إدارة مهام بأولوية وحالة وتاريخ/وقت استحقاق.
- **📁 المستندات**: ربط ملفات موجودة على جهازك (عقود، فواتير، مراسلات...) بعميل معيّن وفتحها مباشرة من داخل البرنامج.

جميع البيانات تُخزَّن محلياً في ملف `office_system.db` (قاعدة بيانات SQLite) داخل مجلد البرنامج — لا حاجة لإنترنت أو خادم خارجي.

## التشغيل

يتطلب Python 3.8+ (يأتي Tkinter مدمجاً مع تثبيت بايثون القياسي على ويندوز).

```
python main.py
```

لا حاجة لتثبيت أي مكتبة خارجية (`pip install` غير ضروري) — كل شيء من مكتبات بايثون القياسية.

## هيكل المشروع

```
OfficeManager/
├── main.py              # نقطة تشغيل البرنامج والنافذة الرئيسية
├── database.py           # الاتصال بقاعدة البيانات وإنشاء الجداول
├── utils.py               # دوال مساعدة (توليد رقم فاتورة، تصدير CSV، فتح ملفات)
├── ui/
│   ├── dashboard_tab.py   # تبويب الرئيسية
│   ├── clients_tab.py     # تبويب العملاء
│   ├── invoices_tab.py    # تبويب الفواتير
│   ├── tasks_tab.py       # تبويب المهام
│   └── documents_tab.py   # تبويب المستندات
├── requirements.txt
└── office_system.db       # يُنشأ تلقائياً عند أول تشغيل
```

## نسخ احتياطي للبيانات

كل بياناتك في ملف واحد: `office_system.db`. لعمل نسخة احتياطية، يكفي نسخ هذا الملف إلى مكان آمن (USB، تخزين سحابي...).

## أفكار للتوسعة لاحقاً

- تصدير الفواتير كملف PDF جاهز للطباعة (عبر مكتبة `reportlab`).
- تذكيرات/إشعارات قبل موعد استحقاق المهام أو الفواتير.
- نسخ احتياطي تلقائي دوري لقاعدة البيانات.
- دعم عدة مستخدمين وصلاحيات.
- قوالب مستندات جاهزة (عقد، عرض سعر) تُملأ تلقائياً ببيانات العميل.
